About

Machine learning, built on strong systems

I’m an M.S. in Computer Science student at UC Davis, where I also earned my B.S. in Computer Science. I focus on machine learning engineering, supported by a strong foundation in software and systems: concurrent services, in-memory databases, and programs that have to remain correct under load.

I build from implementation through evaluation, including PyTorch models and authenticated web applications with real APIs and persistent data. I care about work that others can run and verify.
